# Maeve & Felix — Support

Publieke supportpagina voor **Maeve & Felix — Leren • Ontdekken • Spelen**.

De pagina is bedoeld als Support URL voor App Store Connect.

## Publiceren met GitHub Pages

1. Open **Settings** van deze repository.
2. Ga naar **Pages**.
3. Kies bij **Build and deployment** voor **Deploy from a branch**.
4. Selecteer branch **main** en map **/(root)**.
5. Klik op **Save**.

Daarna wordt de pagina beschikbaar op:

`https://dennishartman.github.io/maeve-felix-support/`
