# Maeve & Felix — Support

Publieke supportpagina voor **Maeve & Felix — Leren • Ontdekken • Spelen**.

De pagina is bedoeld als Support URL voor App Store Connect.

> Deze repository bevat **geen app-broncode**. De iOS/iPadOS-broncode hoort in de aparte private repository `ios-maeve-felix`.

## Belangrijk: repositorynaam

De GitHub Pages-URL is gekoppeld aan de repositorynaam `maeve-felix-support`. Hernoem deze repository daarom niet zonder ook de Support URL en Privacy Policy URL in App Store Connect te controleren en zo nodig bij te werken.

## Publiceren met GitHub Pages

1. Open **Settings** van deze repository.
2. Ga naar **Pages**.
3. Kies bij **Build and deployment** voor **Deploy from a branch**.
4. Selecteer branch **main** en map **/(root)**.
5. Klik op **Save**.

Daarna wordt de pagina beschikbaar op:

`https://dennishartman.github.io/maeve-felix-support/`
